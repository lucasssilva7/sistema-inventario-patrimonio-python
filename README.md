# 🏢 Sistema de Inventário de Patrimônio

Sistema desktop desenvolvido em Python utilizando Tkinter para interface gráfica e SQLite para persistência de dados.

## 🚀 Funcionalidades

- Cadastro de itens
- Atualização de registros
- Exclusão de itens
- Cálculo automático do valor total do inventário
- Contagem total de itens cadastrados
- Upload e visualização de imagem do item
- Interface gráfica intuitiva

## 🛠 Tecnologias Utilizadas

- Python
- Tkinter
- SQLite

## 🧠 Conceitos Aplicados

- Programação orientada a eventos
- CRUD (Create, Read, Update, Delete)
- Integração com banco de dados
- Manipulação de arquivos
- Estruturação de interface desktop

## 🎯 Objetivo

Projeto acadêmico desenvolvido para aplicar conceitos de desenvolvimento de sistemas com interface gráfica e banco de dados relacional.
